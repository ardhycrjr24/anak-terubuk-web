## Overview

Macmo is a native macOS application for working with AI agents.
It gives agent work a fixed place to live: tasks are queued,
runs are visible, and approvals happen in one surface instead of
scattered chat windows.

## Why it exists

Agent workflows today spread across browser tabs, terminals, and chat
threads. State is hard to see and easy to lose. Macmo exists to answer
a practical question: what does a calm, native control surface for
agent work look like on the Mac?

## What is being built

- A task queue for agent jobs, with visible state per run.
- An approval step for actions that need a human decision.
- An activity view that shows what agents did, in order.
- A menu-bar presence for quick access without breaking focus.

## Technology

Macmo is built natively for macOS with Swift and SwiftUI. Native
matters here: menu-bar access, system notifications, and keyboard-first
interaction are part of the design, not add-ons.
